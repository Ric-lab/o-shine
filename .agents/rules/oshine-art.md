# O-Shine persistent rule

@../../AGENTS.md

For any visual game-art, asset, sprite, 3D, VFX, visual redesign, or new-minigame visual task, the O-Shine art pipeline is mandatory.

Use the `oshine-art` skill. Never skip the concept approval gate or bypass the repository job state.

If this rule is shown in Antigravity's Rules UI, configure it as **Always On**.
